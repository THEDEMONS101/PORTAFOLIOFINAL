## 🛠️ Tecnologías Utilizadas
Este portafolio fue construido utilizando las siguientes herramientas:
- **React 18:** Biblioteca principal para la interfaz de usuario.
- **Vite:** Empaquetador y servidor de desarrollo ultrarrápido.
- **CSS3 / Tailwind CSS:** Estilos y diseño responsivo.
- **React Icons:** Librería de iconos.
- **JavaScript (ES6+):** Lógica del lado del cliente.

## ✨ Características
- **Diseño Interactivo:** Interfaz inspirada en editores de código, con navegación fluida entre pestañas.
- **Paleta de Colores Sobria:** Enfoque formal y elegante con tonos neutros y cálidos.
- **Totalmente Responsivo:** Adaptable a dispositivos móviles, tablets y pantallas de escritorio.
- **Modo de Navegación Dual:** Pestañas superiores y menú inferior en móviles para mejor accesibilidad.
- **Secciones Completas:** Inicio, Sobre mí, Proyectos, Cuaderno de apuntes, Reflexión y Bibliografía.
- **Enlaces Directos:** Integración con mis repositorios reales de GitHub para cada práctica.
